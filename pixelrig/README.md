# PixelRig Studio

เครื่องมือ rig ตัวละคร 2D / 2.5D / Pixel บนเบราว์เซอร์ ทำท่าโจมตี อาวุธ และเอฟเฟกต์ แล้วส่งออกเป็นสไปรต์ชีตสำหรับ **Godot 4, Unity, Roblox Studio**
ไม่ต้องติดตั้งอะไร: ดับเบิลคลิก `index.html` ได้เลย

## ทำอะไรได้บ้าง
- **ตัวละครแบบโครงกระดูก** 20 กระดูก สวมใส่ทีละชิ้น (หมวก เสื้อ/เกราะ ถุงมือ กางเกง รองเท้า หน้า ผ้าคลุม) เปลี่ยนสี ทรงผม
- **การเคลื่อนไหวอัตโนมัติ**: ยืนหายใจ เดิน วิ่ง (ปรับความเร็ว ช่วงก้าว สะโพกส่าย มือเอื่อยตาม) ผ้าคลุม/ผมพลิ้วตามแรง เท้าติดพื้นอัตโนมัติ
- **อาวุธ 12 แบบ / 6 สายท่า**: ดาบ มีดสั้น คาตานะ ดาบใหญ่ ขวาน ค้อน หอก เคียว คทา คัมภีร์ ธนู มือเปล่า แต่ละสายมีคอมโบ 3 จังหวะ + สกิล 2 ท่า อาวุธสองมือใช้ IK จับด้ามจริง
- **ท่าทั่วไป**: โดนตี ล้ม ฟื้น นั่ง ฉลองชัย โบกมือ ตั้งการ์ด พุ่งตัว ถอยหลบ
- **เอฟเฟกต์ 17 แบบ**: ฟันโค้ง ประกาย แฟลช ระเบิด คลื่นพื้น เศษหิน ฝุ่น เส้นความเร็ว กระสุนเวท/ธนู/น้ำแข็ง สายฟ้า วงเวท เสาแสง ออร่า อุกกาบาต ฝนธนู เงาติดตาม ตัวเลขดาเมจ
  พร้อม hit-stop จอสั่น หุ่นซ้อมโดนตีกระเด็น ธาตุ 7 สีเปลี่ยนได้ทั้งท่า
- **2.5D**: เดินลึกเข้า-ออกฉาก (↑ ↓) เงาใต้เท้า ท่าหมุนตัวด้วยการพลิกด้าน
- **โหมดภาพ**: Pixel (คมแบบพิกเซลอาร์ตจริง ปรับขนาดพิกเซลได้) หรือ 2D HD (เส้นเรียบ)
- **แก้ท่าเอง**: ลากกระดูกบนจอ (มือ/เท้าเป็น IK) ไทม์ไลน์คีย์เฟรม onion skin ease ต่อคีย์ ดูแบบสโลว์ได้
- **ใช้รูปของคุณเอง**: ใส่ PNG ทีละชิ้นบนกระดูก (หัว ลำตัว แขน ขา อาวุธ) แล้วใช้ท่าทั้งหมดกับงานอาร์ตของคุณ
- **ให้ Claude ช่วย**: กด "คัดลอก Prompt สำหรับ Claude" อธิบายท่าที่อยากได้ แล้ววาง JSON ที่ได้กลับมา หรือสั่ง Claude Code ในโฟลเดอร์นี้ให้เพิ่มท่า/อาวุธ/ชุด/เอฟเฟกต์ได้เลย (ดู `CLAUDE.md`)

## แท็บ "วาดพิกเซล"
โปรแกรมวาดพิกเซลในตัว ใช้วาดชิ้นส่วนตัวละครแล้วเห็นผลบนตัวละครที่ขยับอยู่ทันที หรือวาดสไปรต์อิสระแล้วส่งออก PNG
- **เครื่องมือ:** ดินสอ Pixel-perfect (ลบมุมหยักอัตโนมัติ) · ยางลบ · ถังเท (ติดกัน/ทั้งภาพ) · เส้นตรง · สี่เหลี่ยม · วงรี (โปร่ง/ทึบ, Shift = 45°/จัตุรัส/วงกลม) · ดูดสี (Alt) · เลือกพื้นที่ · ย้าย · แรเงาตามพาเลต · ดิทเธอร์ · หัวแปรง 1–12 (เหลี่ยม/กลม) · สมมาตรซ้าย-ขวา/บน-ล่าง
- **งาน:** เลเยอร์ (ซ่อน ล็อก เปลี่ยนชื่อ เรียงลำดับ ทำสำเนา รวมลง) · undo/redo 120 ขั้น · คัดลอก/วาง · พลิก หมุน 90° · เส้นขอบรอบรูป (4 หรือ 8 ทิศ) · ปรับขนาดผ้าใบ · นำเข้า/ส่งออก PNG (ขยาย ×1–×8)
- **สี:** สีหลัก/สีรอง (คลิกซ้าย/ขวา) · พาเลตไล่เฉดแบบเลื่อน hue (เงาออกน้ำเงิน แสงออกเหลือง) · พาเลตจากสีตัวละคร · ดึงสีจากภาพ
- **วาดชิ้นส่วนตัวละคร:** เลือกชิ้น (หัว ลำตัว แขน ขา อาวุธ ผ้าคลุม...) → "เปิดมาวาด" เริ่มจากรูปทรงเดิมที่แปลงเป็นพิกเซลแล้ว หรือผ้าใบว่างที่มีรูปเดิมเป็นไกด์ · จุดแดง = ข้อต่อกระดูก · วาดแขน/ขาครั้งเดียวได้ทั้งสองข้าง (ข้างหลังมืดลงให้อัตโนมัติ) · ชิ้นที่วาดจะไปอยู่ในสไปรต์ชีตและ rig ที่ส่งออกด้วย
- **ปุ่มลัด:** B E G L R O I M V S D · X สลับสี · [ ] ขนาดหัวแปรง · Ctrl+Z/Y · Ctrl+C/V · Del · Enter · Space+ลาก เลื่อนจอ · ล้อเมาส์ ซูม · 0 พอดีจอ
- **อนิเมชันทีละเฟรม (ไทม์ไลน์ใต้ผ้าใบ):** รูปย่อทุกเฟรม · เพิ่ม/ทำสำเนา/ลบ/ย้ายเฟรม · เวลาแต่ละเฟรม (ms) หรือตั้ง FPS ทั้งหมด · Onion skin (เฟรมก่อนสีแดง เฟรมถัดไปสีน้ำเงิน) · เล่นวน / เล่นไป-กลับ · **แท็ก** ตั้งชื่อช่วงเฟรมเป็นท่า (เช่น idle, slash) แล้วเล่นเฉพาะช่วงได้ · เลเยอร์และการพลิก/หมุน/ปรับขนาดใช้กับทุกเฟรม
- **ส่งออกอนิเมชัน:** ZIP สำหรับ Godot (SpriteFrames หนึ่งแท็ก = หนึ่ง animation พร้อมเวลาแต่ละเฟรม) · Unity (เฟรมแยกโฟลเดอร์ตามท่า) · Roblox (Luau พร้อมเวลาแต่ละเฟรม) · JSON แบบ Aseprite · หรือ PNG สไปรต์ชีตอย่างเดียว · **นำเข้าสไปรต์ชีต** แล้วตัดเป็นเฟรมตามขนาดช่อง
- **บันทึกงาน:** บันทึกอัตโนมัติทุกครั้งที่แก้ (รีโหลดแล้วเปิดกลับมาเอง) · คลังงานวาดตั้งชื่อได้ · ไฟล์ `.pxrig` ไว้ย้ายเครื่อง · "ส่งออกโปรเจกต์" รวมงานวาดไปด้วย
- ปุ่มลัดเฟรม: `,` `.` เฟรมก่อน/ถัดไป · P เล่น/หยุด · Shift+N เฟรมว่าง · Shift+D ทำสำเนาเฟรม
ยังไม่มี: การเปิดไฟล์ .aseprite โดยตรง (ส่งออกจาก Aseprite เป็นสไปรต์ชีต PNG แล้วนำเข้าได้)

## ตัวละครสำเร็จรูป
เลือกได้ที่แท็บ "ทดสอบท่า" → "ตัวละครสำเร็จรูป" หรือคลังตัวละครในแท็บตั้งค่า
- **เซียนอัสนีทอง:** เซียนผมยาวชุดคลุมดำปักลายทอง เสื้อคลุมยาวปลิวตามแรง ถือกระบี่ ธาตุอัสนีทอง เดินสง่ามือไพล่หลัง · คอมโบ: กระบี่ปาดลม → กระบี่ผ่าฟ้า → อัสนีตัดเงา (พุ่งทะลุ + สายฟ้าฟาด) · สกิล K: ฝ่ามืออัสนี · สกิล L: สายฟ้าสวรรค์
อยากได้ตัวละครใหม่ ส่งภาพอ้างอิงให้ Claude แล้วสั่งให้ทำ "character pack" (ดู CLAUDE.md)

## ส่งออกไปเกม
แท็บ **ส่งออก** → เลือกท่า → **ดาวน์โหลด ZIP** ได้ไฟล์:
| ไฟล์ | ใช้กับ |
|---|---|
| `<ชื่อ>.png` + `<ชื่อ>.json` | สไปรต์ชีต + ข้อมูลเฟรมแบบ Aseprite (แท็กท่า, จุดหมุนที่เท้า, เฟรมที่โดนตี, root motion) ใช้ได้ทุกเอนจิน |
| `godot/<ชื่อ>.tres` | Godot 4: SpriteFrames ใส่ AnimatedSprite2D ได้ทันที |
| `unity_frames/<ท่า>/*.png` | Unity: ลากเฟรมของแต่ละท่าลงซีน Unity สร้าง Animation ให้ (หรือสไลซ์ชีตแบบ Grid) |
| `roblox/<ชื่อ>_sprite.lua` | Roblox: ModuleScript เล่นอนิเมชันบน ImageLabel พร้อม callback เฟรมโดนตี |
| `README.txt` | ขั้นตอนนำเข้าแต่ละเอนจินแบบละเอียด |

### ส่งออกโครงกระดูก (Skeletal rig)
การ์ด **ส่งออกโครงกระดูก** ในแท็บส่งออก: ตัดตัวละครเป็นชิ้นส่วนติดกระดูก แล้วให้เอนจินขยับกระดูกเอง (ภาพลื่นทุกขนาด ไฟล์เล็ก ผสม/ปรับท่าในเอนจินได้)
| โฟลเดอร์ใน ZIP | ใช้กับ |
|---|---|
| `godot/rigs/<ชื่อ>/` | Godot 4: ฉาก `.tscn` (Skeleton2D + Bone2D + Sprite2D + AnimationPlayer ทุกท่า) สคริปต์มีสัญญาณ `rig_event("hit")`, `play()`, `set_facing()` |
| `unity/Assets/PixelRig/` | Unity: คลิกขวาไฟล์ `.rig.json` → PixelRig → Build Rig Prefab ได้ Prefab + Animation Clip + Animator Controller และ event `OnRigEvent("hit")` |
| `roblox/` | Roblox: ModuleScript ขยับ ImageLabel ทีละชิ้น `rig:Play("walk")`, `rig:SetFacing(-1)`, `rig.OnEvent` |
| `<ชื่อ>.rig.json` + `parts/` | รูปแบบกลาง (กระดูก ชิ้นส่วน คีย์เฟรม) สำหรับเอนจินอื่น |

ตรวจแล้ว: Godot 4.7 เปิดฉากได้ ตำแหน่งกระดูกตรงกับในแอป (คลาดไม่ถึง 0.01px) และ event ยิงถูกเฟรม · สคริปต์ Unity คอมไพล์ผ่าน แต่ยังไม่ได้รันใน Unity Editor จริง · Roblox ยังไม่ได้รันใน Studio จริง
ข้อจำกัด: ร่องรอยอาวุธ/เอฟเฟกต์/สายธนูไม่อยู่ใน rig (ส่งออกเอฟเฟกต์เป็นสไปรต์ชีตแยก) · ภาพพิกเซลจะหมุนเป็นบิตแมป ถ้าต้องการพิกเซลคมทุกเฟรมใช้สไปรต์ชีต

เคล็ดลับ: Roblox ย่อรูปที่ใหญ่กว่า 1024px ให้เลือก "ขนาดชีตสูงสุด 1024" หรือติ๊ก "แยกไฟล์ต่อท่า" · ติ๊ก "ล็อกกับที่" เพื่อให้เกมเป็นคนขยับตัวละครเอง · ปิด "ตัวละคร" เพื่อส่งออกเอฟเฟกต์อย่างเดียว
